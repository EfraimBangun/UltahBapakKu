WEBSITE ULANG TAHUN BAPAK — VERSI 2
======================================

Ini adalah versi baru yang konsepnya dibuat ulang dari nol:
- editorial / family keepsake
- warna kertas, hitam, cokelat, emas
- tidak memakai card-grid berlebihan
- animasi lebih halus
- banyak whitespace
- personal dan tidak terlihat seperti template AI

CARA PAKAI
----------
1. Extract ZIP.
2. Buka index.html.
3. Untuk foto, masukkan:
   foto/bapak-utama.jpg
   foto/kenangan-1.jpg
   foto/kenangan-2.jpg
   foto/kenangan-3.jpg
4. Tidak wajib memasukkan musik. Website sudah punya efek suara sederhana dari Web Audio.
5. Kalau punya lagu sendiri, masukkan file musik/musik.mp3. 
   Untuk versi ini tombol musik menggunakan Web Audio sebagai ambience sederhana;
   kode dapat dikembangkan untuk file musik jika diperlukan.

KONTEN YANG BISA DIGANTI
-------------------------
- tanggal di hero
- nama anak pada surat
- timeline cerita
- caption foto
- doa
- foto keluarga

CATATAN
-------
Website dibuat single-file agar mudah dipindahkan ke Firebase/Vercel/hosting biasa.
Tidak membutuhkan API, database, Firebase, atau server.
